## 五、坑与约定（血泪清单）

1. **id 前缀必须全局唯一**。`window.HNSF829_Q` 是全局数组，重复 id 会被**静默丢弃**（曾因 `lc` 被两章同时使用，12 题丢失）。
2. **LaTeX 反斜杠一律双写**：源码写 `\\(` → 运行值 `\(`。
3. **JS 字符串统一单引号，字符串内绝不能出现半角单引号**。导数撇号写 `^{\\prime}`，不要写 `'`。
4. **LaTeX 定界符必须配对**：`\(` 与 `\)`、`\[` 与 `\]`、`\begin{xxx}` 与 `\end{xxx}`。校验脚本会查。
5. **check-bank.js 的 id 前缀校验**用 `split` 计数，不用 RegExp（PowerShell 下正则反斜杠转义极易写错）。
6. 只要节点 `wip: false` 就必须有题，否则点了弹「补充中」——属体验缺陷，校验脚本会 warn。
7. 题库文件接入顺序：必须在 `data-links.js` / `store.js` / `engine.js` 之前。
8. 存档是 v2 格式，旧节点 id 通过 `store.js` 的 `LEGACY_NODE_MAP` 迁移，改节点 id 时要同步维护这张表。
9. 子代理（general_purpose_task）并行生成题库时**结果频繁丢失**，必须检查文件是否真正落地，必要时重跑。
10. **`数学二/` 整个目录在 git 里仍未跟踪**（`git status` 显示 `?? 数学二/`）——728 题题库 + 全部改动都还没进版本库，只有线上快照可回溯。建议尽快首次提交。
