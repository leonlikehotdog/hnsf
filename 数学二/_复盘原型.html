回炉间第 1 章 极限的定义与性质 对手：你自己的暗影
回炉进度6 / 9
① 诊断屏15 秒 · 不给做题
当时你选了 B：
B∃ε>0, ∀δ>0，当 0<|x−x₀|<δ 时，恒有 |f(x)−A|<ε
量词顺序被颠倒，写成「存在一个 ε，对任意 δ」，把「任意小」偷换成「存在一个小」； 只记住「有两个正数」而没记清谁控制谁的同学最容易选它。
A∀ε>0, ∃δ>0，当 0<|x−x₀|<δ 时，恒有 |f(x)−A|<ε
🥋 师傅：你不是不会极限，是量词的次序没记牢 —— 记住「任意 ε 决定后面所有的 δ」， 这一族的题你就全通了。
② 变形屏同类变式 · 不是原题
同一坑再考一次第 2 次变形会更狠
把 \(x\to x_0\) 换成 \(x\to+\infty\)，则 \(\lim\limits_{x\to+\infty}f(x)=A\) 的定义是（ ）
A\(\forall\varepsilon>0,\ \exists X>0\)，当 \(x>X\) 时，恒有 \(|f(x)-A|<\varepsilon\)
B\(\exists\varepsilon>0,\ \forall X>0\)，当 \(x>X\) 时，恒有 \(|f(x)-A|<\varepsilon\)
C\(\forall X>0,\ \exists\varepsilon>0\)，当 \(x>\varepsilon\) 时，恒有 \(|f(x)-A|<X\)
D\(\forall\varepsilon>0,\ \exists X>0\)，当 \(|x|>X\) 时，恒有 \(|f(x)-A|<\varepsilon\)
D 项是原题 D 项（漏条件）的变体：把「去心邻域」漏成「\(x\to 0\) vs \(x\to\infty\)」—— 同一类错误换了个位置，这才是有效的复盘。

4 ·数据落地（P0，半天）

不动界面也能先修好"复盘失效"的根。旧存档缺字段一律按新错处理，不回退任何已通关进度。

// store.js —— state.wrong[qid] 从布尔升级成段位
{
  node, ts, times,            // 已有
  picked: 1,                  // ★新增：学生当时选了什么（下标或文本）
                              //   没它就没有「诊断屏」
  stage: 1,                   // 0 新错 → 1 变形题答对 → 2 隔天再答对 → 3 出炉
  due: 1792280000000,         // ★新增：下次可回炉时间
  usedVariants: [0],          // ★新增：用过哪些变式，避免重复
  rightStreak: 0              // 连错 2 次就移出回炉间，交给师傅
}
// 判定规则（唯一的强制点）
function advance(qid, okIsVariant) {
  const w = state.wrong[qid];
  if (!w) return;
  if (!okIsVariant) { w.rightStreak = 0; return; }   // 答错：只清连对
  if (Date.now() < w.due) return;                    // 没到间隔：不给进度
  w.stage++;
  w.usedVariants.push(curVariant);
  w.due = nextDay04(w.ts);                           // ★ 真·隔天
  if (w.stage >= 3) resolveWrong(qid, true);         // 出炉
}

// recordAnswer 不再一答对就销账
// if (correct) state.wrong[qid].resolved = true;   ← 删掉这行

容错两处：① 隔天按「跨过凌晨 4 点」算，熬夜党不会被卡； ② due 依赖系统时间，自用系统不设防。

5 ·"自动换数字"要说清楚：这不是正则能做的

你选了自动换数字，但必须诚实说一句：386 道没有变式的题，换数字后答案也跟着变， 靠脚本正则改不出来。这条路只能这么走 👇

✅ 可行做法：离线生成 + 交叉验算
按你题库现有的 variants: [{stem, hint}] 约定（hint 里带答案/思路）， 逐题生成一道同结构、换参数的变式，写进 data-q-*.js。
· 选择题：必须给出新的正确项，并保证它恰好有一个最优解
· 填空题：必须重新算出新答案，且加进可接受写法数组
· 解答题 / 证明题：这类不要换数字 → 结构性变式或降级为「看解析复述」自评
⚠️ 一条铁律
生成错的变式，比没有变式更糟。考研数学二靠这个提分，答案错了会直接教坏人。

所以：
· 生成后逐题验算，脚本只能查结构（选项数/答案存在/LaTeX 闭合）， 数值必须真算一遍
· 优先补高频易错的题，不追求 100% 覆盖
· 没变式的题在回炉间里直接标「原题重做」，不假装它是变式
原型稿 · 未接任何真实逻辑，纯静态。
