## 二、题目对象字段

**除 `options` / `optionNotes`（仅 choice 题有）与 `keys`（calc/proof/app 必填、choice/blank 可省）外，
下面每个字段每题都必须有。**

| 字段 | 说明 |
|---|---|
| `id` | 全局唯一。格式 `<前缀>-<序号>`，前缀见第三节表格 |
| `node` | 只能是本文件负责的节点 id |
| `level` | 该节点所属层：1 基础简易 / 2 综合应用 / 3 创新拓展 —— 与 `data-nodes.js` 里该节点的 `tier` 一致 |
| `type` | `choice` 选择 / `blank` 填空 / `calc` 计算（含解答题）/ `proof` 证明 / `app` 应用 |
| `score` | 整数 2~8。选择/填空用 2~4，解答/证明/应用用 5~8 |
| `diff` | `basic` 基础 / `exam` 真题 / `hard` 拔高。每个节点内 basic ≈ 35%、exam ≈ 45%、hard ≈ 20% |
| `stem` | 题干。**多问大题必须写成 (1)(2)(3) 形式**；calc 题里至少 40% 是多问递进题 |
| `options` | 仅 choice：恰好 4 个选项的字符串数组 |
| `answer` | choice → 正确选项下标（0 起，数字）；blank → **可接受答案字符串数组，≥2 种等价写法**；calc/proof/app → 参考答案文本（含关键步骤，可用 `\n` 分行） |
| `keys` | 得分点数组，每条自带分值，如 `'写出特征方程并解出特征值 （3 分）'`。calc/proof/app 必填 3~5 条，**分值合计等于 score** |
| `tips` | 踩分技巧：算不出来时怎么写能抢过程分、什么时候该果断放弃。**每题都要有**，一句话 |
| `optionNotes` | 仅 choice：长度**必须等于** `options` 长度。正确项写 `'正确。<为什么对>'`；错误项写 `'<错在哪一步>；<谁最容易选它>'` |
| `analysis` | 五段式解析，见第四节 |
| `variants` | 数组 `[{ stem: '...', hint: '...' }]`，**只给题干与提示，不给答案**。本文件中至少 25% 的题要带（每题带 1 道） |
| `source` | 溯源，如 `'同济《高等数学》第七版 上册 第3章 第1节 · 微分中值定理'` |

## 四、analysis 五段式

用 `\n` 分隔，每段以【】开头，写成"老师带读"的口吻：

```
【考查点】考什么、属于大纲哪个知识点、大概值几分
【入口】第一眼看什么、先做哪个判断（要具体，例如"先判型：分子分母都趋于 0，是 0/0 型"）
【关键推导】完整推导步骤，每步说清怎么来的（含算式）
【结论】最终答案
【易错】最容易踩的坑 + 易混知识点的对照辨析
```

**绝对不要只报答案。** 要写清"为什么第一步这么做"的思路。

## 五、数学与语法硬规则（违反会导致页面白屏）

1. 数学公式一律 LaTeX：行内 `\\( ... \\)`，独立成行 `\\[ ... \\]`。
2. JS 字符串统一用**单引号**，字符串里**绝对不能出现半角单引号 `'`**。
   导数撇号一律写 `^{\\prime}`（如 `f^{\\prime}(x)`），不要写 `f'(x)`；英文所有格也不要写。
3. 源码里 LaTeX 的反斜杠**一律双写**（源码 `\\(` → 运行值 `\(`）。
4. `<` `>` 可以直接写；更推荐 `\\lt`、`\\gt`、`\\leqslant`、`\\geqslant`。
5. 不要出现 `</script>`、`<!--` 等会破坏 HTML 的片段。
6. 不用 ES6 模板字符串；不用箭头函数以外的 ES6 语法（`var` / `function` 为主）。
7. **每题都要实际算一遍**，确认 `answer` 与 `analysis` 的结论一致；
   choice 的 `answer` 下标必须确实指向正确选项；`optionNotes` 长度必须等于 `options` 长度。

## 六、质量要求（用户明确提的四条，必须全部落地）

1. **真题风格多问大题**：calc 题尽量 2~3 问递进，至少 40% 是多问。
2. **干扰项逐条批驳**：choice 题必须写 `optionNotes`，说清每个错误选项错在哪一步、谁最容易选它。
3. **难度分级 + 同类变式**：每题标 `diff`；至少 25% 的题带 `variants`（只给题干+提示）。
4. **得分点与踩分技巧**：calc/proof/app 必须有 `keys`（带分值）与 `tips`。
