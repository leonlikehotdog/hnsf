🎬 什么是微分方程？你能在 30 秒内意会

你学了导数（ch02）：知道 y 就能算 y'

你学了积分（ch03）：知道 y' 就能反推 y

但物理学家扔给你一个问题：

"我不知道 y，但我知道 y 和 y' 的关系。你能反推 y 是什么吗？"

这就是微分方程：把"函数 + 它的导数"混在一起的方程。世界是个变化的世界，所以世界几乎所有规律都是微分方程。

⏳ 350 年常微分方程史 · 让宇宙"会算"
📖 牛顿第二定律 F = ma
1687 牛顿："给我力，我能算一切"

🎯它是为了解决什么问题？

1665 年伦敦大瘟疫，牛顿躲到乡下。看着苹果落地，他在想一个只有 1 岁的孩子才能问的"笨"问题：

"为什么苹果往下掉而不往上飞？"

其实更复杂：苹果从树上掉下来，下落速度越来越快 —— 这是"加速度"。加速度来自力。这条链子就是：

F = m · a ↔ F = m · a'' ↔ m·d²x/dt² = F

1687 年牛顿在《自然哲学的数学原理》(Principia) 中把这个方程写出来，并用它解释了行星运动、潮汐、苹果落地三大看似无关的现象。

"我不用假设 — 我用方程式能告诉你月球为什么绕地球转、苹果为什么落。" —— 牛顿《原理》1687

📱今天有什么用？

① 手机计步：加速度传感器每秒钟测三轴的 a 变化，用 F = ma 反推你走了多少步

② 游戏人物移动：跳跃曲线 = 二次积分 m·d²y/dt² = -mg

③ SpaceX 火箭回收：实时求解 6 自由度的牛顿方程，让火箭精确落地

📖 指数增长 dy/dt = ky
1690 雅各布·伯努利："人口 = e 的人间化身"

🎯它是为了解决什么问题？

1690 年巴黎在闹瘟疫，法国主教问数学家："巴黎人口会无限制增长吗？"

雅各布·伯努利的回答是：会（在没有资源限制的情况下）。他写下：

dy/dt = k·y → y(t) = y₀·e^(kt)

这就是指数增长方程 —— 跟你在 ch01 看到的复利问题是一回事（连续利滚利 + 指数增长 = 同一件事）。

"如果人口不设上限，100 年后人类都要把地球挤爆。" —— 雅各布（有点夸张，但意思到了）

📱今天有什么用？

① 疫情预测：每天感染人数的指数增长期，用这个微分方程拟合

② 放射性碳-14 测年：m(t) = m₀·e^(-λt)，λ 是衰变常数

③ 贷款复利：你信用卡欠款按月结，一年后你欠的就是本金 × e^(年利率)

📖 弹簧振动 y'' = -ω²y
1740 欧拉："吊灯的摆动是 sin 函数"

🎯它是为了解决什么问题？

伽利略年轻时，注意到礼拜堂里的吊灯总是左右晃一下又回来。他敏锐地提出：摆动周期只跟"绳长 + 重力加速度"有关，跟"摆幅多大"无关（这就是"等时性"）。

170 年后，欧拉把这个直觉变成方程：

m·y'' + k·y = 0 → y = C·cos(√(k/m)·t + φ)

解完后的形式竟然是个三角函数。这解释了为什么"单摆永远以同样的频率摆" —— 即便把它晃得很厉害，周期还是几乎不变（小幅时）。

"几乎所有的'周期性'自然界，都是这个方程的近亲。" —— 欧拉

📱今天有什么用？

① 机械手表：里面的摆轮 = 弹簧振动方程 y'' = -ω²y

② 电子电路：LC 振荡电路 = 数学形式一样的方程

③ 地震预警：建筑物振动分析 = 高阶版弹簧方程

📖 一阶线性微分方程
1700s 莱布尼茨：「加法扰动也能解」

🎯它是为了解决什么问题？

最朴素的微分方程：y' + P(x)y = Q(x)。这是"y 的增长率 = 某个外力 Q - 某个内部阻力 P·y"。

莱布尼茨给出一个"长但万能"的解法：

y = e^(−∫P dx) · [∫Q·e^(∫P dx) dx + C]

本质上是两步法：① 乘上一个"积分因子"让左边凑成 (y·I)' 形式；② 直接积分。

"这个公式像瑞士军刀 — 看上去复杂，但任何一阶线性方程都能用它拆。" —— 莱布尼茨

📱今天有什么用？

① RLC 电路：电流随时间的变化 = 经典一阶线性方程

② 人口增长 + 食物限制：y' = a·y − b·y² 看起来非线，但 +− 可以分开算

📖 二阶常系数 + 特征方程
1740 欧拉的"代数替代微分"绝技

🎯它是为了解决什么问题？

想解 y'' + p·y' + q·y = 0 这种二阶方程。但求导操作太麻烦。

欧拉的绝招：假设解就是 e^(rx)。代进去，求导 → e^(rx) 自动求导就是 r·e^(rx)。

代入得：e^(rx) · (r² + p·r + q) = 0 → 特征方程：r² + p·r + q = 0

微分方程竟然变成了代数方程 ！这就是特征方程法。然后根据根的 3 种情况（两实根 / 重根 / 共轭复根），写出 3 种不同的解。

"把'微分'替换成'代数' — 这才是最深的数学把戏。" —— 欧拉

📱今天有什么用？几乎所有"会晃的东西"（桥梁、机械臂、芯片减震器）都靠这个方程做稳定性分析。

📖 二阶常系数齐次微分方程

y'' + py' + qy = 0，写特征方程 r² + pr + q = 0：

  • 两个不等实根 r₁ ≠ r₂：y = C₁er₁x + C₂er₂x
  • 重根 r₁ = r₂ = r：y = (C₁ + C₂x)erx
  • 共轭复根 r = α ± βi：y = eαx(C₁cos βx + C₂sin βx)
📝 例题
求微分方程 y' + 2y = ex 的通解
这是一阶线性微分方程，P(x) = 2，Q(x) = ex。
∫Pdx = 2x，e∫Pdx = e2x，e-∫Pdx = e-2x。
y = e-2x[∫ex·e2xdx + C] = e-2x[∫e3xdx + C] = e-2x[e3x/3 + C] = ex/3 + Ce-2x

📝 近五年真题 2 | 2022 数一 | 填空题 · 5分
微分方程 \(y″ + 4y′ + 4y = e^{2x}\) 的通解为 \(y =\) ______。

🎯 出题人考察点（这是高频考点！）

二阶常系数线性非齐次微分方程；特征方程；特解的求法

🧭 解题思路（小白逐步版）

步骤 1 · 解特征方程

特征方程 \(r^2 + 4r + 4 = 0\)，\((r+2)^2 = 0\)，\(r_1 = r_2 = -2\)（二重根）。
齐次通解：\(y_h = (C_1 + C_2 x) e^{-2x}\)。

步骤 2 · 求特解

右端 \(f(x) = e^{2x}\)，\(2\) 不是特征根。
设特解 \(y^* = A e^{2x}\)，代入：
\(y^{*′} = 2Ae^{2x}, y^{*″} = 4Ae^{2x}\)
\(4Ae^{2x} + 4 \cdot 2Ae^{2x} + 4Ae^{2x} = e^{2x}\)
\(A(4 + 8 + 4) = 1\)，\(16A = 1\)，\(A = \dfrac{1}{16}\)。

步骤 3 · 通解

\(y = (C_1 + C_2 x) e^{-2x} + \dfrac{1}{16} e^{2x}\)

📝 近五年真题 3 | 2023 数一 | 选择题 · 5分
若微分方程 \(y^{\prime\prime} + ay^{\prime} + by = 0\) 的解在 \((-\infty, +\infty)\) 上有界，则
A. \(a < 0, b > 0\)
B. \(a > 0, b > 0\)
C. \(a = 0, b > 0\)
D. \(a = 0, b < 0\)

🎯 出题人考察点（这是高频考点！）

常系数齐次线性微分方程；解的有界性

🧭 解题思路（小白逐步版）

步骤 1 · 思维导图

【题目要求】所有解在 \(( -\infty,+\infty )\) 上有界
└─ 写特征方程 \(\lambda^2+a\lambda+b=0\)
　　└─ 计算判别式 \(\Delta=a^2-4b\)
　　　　├─ \(\Delta>0\)：两个不同实根 → 解含 \(e^{\lambda x}\) → 非零实根总在某一端爆炸
　　　　├─ \(\Delta=0\)：二重实根 → 解含 \(xe^{\lambda x}\) → 无法保证全轴有界
　　　　└─ \(\Delta<0\)：共轭复根 \(\alpha\pm\beta i\)
　　　　　　└─ 通解 \(e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)\)
　　　　　　　　├─ 正弦、余弦有界，\(\beta\) 控制振荡
　　　　　　　　└─ \(e^{\alpha x}\) 控制振幅 → 全轴有界要求 \(\alpha=0\)
　　　　　　　　　　└─ 根与系数：\(2\alpha=\lambda_1+\lambda_2=-a\)，再结合 \(\Delta<0\) 判断 \(b\)

【口诀】实根看指数，复根看实部，重根别漏 \(x\)，全轴两边都要顾。

步骤 2 · 特征方程

特征方程 \(\lambda^2 + a\lambda + b = 0\)。

步骤 3 · 分析 \(\Delta > 0\) 与 \(\Delta = 0\)

当 \(\Delta > 0\) 时有两个不同实根 \(\lambda_1, \lambda_2\)，解为 \(y = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}\)，在 \(( -\infty, +\infty )\) 上无界。
当 \(\Delta = 0\) 时有重根，解含 \(x e^{\lambda x}\) 项（\(C_2 \neq 0\) 时），同样无界。

步骤 4 · 分析 \(\Delta < 0\)

当 \(\Delta < 0\) 时根为 \(\lambda_{1,2} = -\dfrac{a}{2} \pm \dfrac{\sqrt{4b-a^2}}{2}\mathrm{i}\)，
通解 \(y = \mathrm{e}^{-\frac{a}{2}x}\left(C_1\cos\dfrac{\sqrt{4b-a^2}}{2}x + C_2\sin\dfrac{\sqrt{4b-a^2}}{2}x\right)\)。
要在 \(( -\infty, +\infty )\) 有界，必须 \(\mathrm{e}^{-\frac{a}{2}x}\) 有界，即 \(a = 0\)；又由 \(\Delta = a^2 - 4b < 0\) 知 \(b > 0\)。

步骤 5 · 结论

选 C：\(a = 0, b > 0\)。

① 写出关键思路 (3分)；② 计算正确 (2分)

⚠️ 小白踩坑预警（错一个扣 2~4 分）

混淆有界与稳定；忽略 \(\Delta < 0\) 时指数因子对有界性的影响

📝 近五年真题 4 | 2023 数一 | 解答题 · 10分
设曲线 \(y = y(x)(x > 0)\) 经过点 \((1, 2)\)，该曲线上任一点 \(P(x, y)\) 到 \(y\) 轴的距离等于该点处的切线在 \(y\) 轴上的截距。
(1) 求 \(y(x)\)；
(2) 求函数 \(f(x) = \displaystyle\int_1^x y(t),dt\) 在 \((0, +\infty)\) 上的最大值。

🎯 出题人考察点（这是高频考点！）

微分方程建模；切线方程；变上限积分

🧭 解题思路（小白逐步版）

步骤 1 · 思维导图：微分方程几何建模

【核心思想】将几何语言翻译成微分方程，求解后求极值
【解题框架】
└─ 第一问：求曲线方程
　　├─ ① 写切线方程：\(Y - y = y'(X - x)\)
　　├─ ② 求 \(y\) 轴截距：令 \(X=0\)，得 \(Y = y - xy'\)
　　├─ ③ 依题意列方程：截距 = 到 \(y\) 轴距离（即 \(x\)）
　　└─ ④ 解一阶线性微分方程，代入初始点求特解
└─ 第二问：求变上限积分的最大值
　　├─ ① 求导找驻点：\(f'(x) = y(x) = 0\)
　　├─ ② 判断单调性：确认是极大值点
　　└─ ③ 分部积分计算该点处的定积分值

【口诀】切线截距公式背，列出方程套公式；求导找零判极值，分部积分要仔细。

步骤 2 · (1) 翻译几何条件，列微分方程

曲线上点 \(P(x, y)\) 处的切线方程为 \(Y - y = y'(X - x)\)。
求在 \(y\) 轴上的截距，令 \(X = 0\)，得到 \(Y = y - xy'\)。
点 \(P(x,y)\) 到 \(y\) 轴的距离为 \(|x|\)，因为题目已知 \(x > 0\)，距离就是 \(x\)。
根据题意：\(y - xy' = x\)。
整理成标准一阶线性微分方程形式：\(y' - \dfrac{1}{x}y = -1\)。

步骤 3 · 求解一阶线性微分方程

套用公式 \(y = e^{-\int P(x)dx} \left[ \int Q(x)e^{\int P(x)dx} dx + C \right]\)。
这里 \(P(x) = -\dfrac{1}{x}, Q(x) = -1\)。
积分因子 \(e^{\int P(x)dx} = e^{-\ln x} = \dfrac{1}{x}\)；\(e^{-\int P(x)dx} = x\)。
代入公式：\(y = x \left[ \int (-1) \cdot \dfrac{1}{x} dx + C \right] = x(-\ln x + C)\)。
由初始条件曲线过点 \((1, 2)\)，代入 \(x=1, y=2\)：\(2 = 1 \cdot (-\ln 1 + C) \Rightarrow C = 2\)。
所以曲线方程为 \(y = x(2 - \ln x)\) 。

步骤 4 · (2) 求变上限积分函数的驻点

目标函数 \(f(x) = \displaystyle\int_1^x t(2 - \ln t)dt\)。
求导：\(f'(x) = x(2 - \ln x)\)。
令 \(f'(x) = 0\)，因为 \(x>0\)，只能是 \(2 - \ln x = 0\)，解得驻点 \(x = e^2\)。
当 \(0 < x < e^2\) 时，\(2 - \ln x > 0\)，\(f'(x) > 0\)（函数递增）；
当 \(x > e^2\) 时，\(2 - \ln x < 0\)，\(f'(x) < 0\)（函数递减）。
所以 \(x = e^2\) 是唯一极大值点，也是全局最大值点。

步骤 5 · 计算最大值（分部积分）

计算 \(f(e^2) = \displaystyle\int_1^{e^2} t(2 - \ln t)dt\)。
使用分部积分法（反对幂指三，对数当 \(u\)，多项式当 \(v'\)）：
\(\displaystyle\int t(2 - \ln t)dt = \int (2 - \ln t) d\left(\dfrac{t^2}{2}\right)\)
\(= \dfrac{t^2}{2}(2 - \ln t) - \int \dfrac{t^2}{2} d(2 - \ln t)\)
\(= \dfrac{t^2}{2}(2 - \ln t) - \int \dfrac{t^2}{2} \left(-\dfrac{1}{t}\right) dt\)
\(= \dfrac{t^2}{2}(2 - \ln t) + \int \dfrac{t}{2} dt = \dfrac{t^2}{2}(2 - \ln t) + \dfrac{t^2}{4}\)。
代入上下限 1 到 \(e^2\)：
上限代入：\(\dfrac{e^4}{2}(2 - 2) + \dfrac{e^4}{4} = \dfrac{e^4}{4}\)
下限代入：\(\dfrac{1}{2}(2 - 0) + \dfrac{1}{4} = 1 + \dfrac{1}{4} = \dfrac{5}{4}\)
相减得到最大值：\(\dfrac{e^4}{4} - \dfrac{5}{4}\) 。

📝 近五年真题 5 | 2024 数一 | 填空题 · 5分
微分方程 \(y' = \frac{1}{(x + y)^2}\) ，满足条件 \(y(1) = 0\) 的解为 14.

🎯 出题人考察点（这是高频考点！）

正态分布

🧭 解题思路（小白逐步版）

步骤 1 · 作代换降阶

令 \(u=x+y\)，则 \(y\prime=u\prime-1\)。原方程变为
\[u\prime-1=\frac1{u^2},\qquad u\prime=1+\frac1{u^2}=\frac{u^2+1}{u^2}.\]

步骤 2 · 分离变量积分

于是
\[\frac{dx}{du}=\frac{u^2}{u^2+1}=1-\frac1{u^2+1}.\]
积分得
\[x=u-\arctan u+C.\]

步骤 3 · 代入初值

由 \(y(1)=0\) 得 \(u(1)=1\)。因此
\[1=1-\arctan1+C\Rightarrow C=\frac\pi4.\]故
\[x=u-\arctan u+\frac\pi4.\]

步骤 4 · 化成题目常见写法

把 \(u=x+y\) 代回，得 \(\arctan(x+y)=y+\dfrac\pi4\)，于是
\[x+y=\tan\left(y+\frac\pi4\right),\qquad x=\tan\left(y+\frac\pi4\right)-y.\]
