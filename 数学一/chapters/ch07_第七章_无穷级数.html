📖 调和级数 1+1/2+1/3+...
1689 兄弟反目：一个差点毁了伯努利家族的问题

🎯它是为了解决什么问题？

雅各布·伯努利在 1689 年研究"无穷多个分数加起来等多少"。他注意到：

1 + 1/2 + 1/4 + 1/8 + 1/16 + ... = 2（等比级数收敛）✓

1 + 1/2 + 1/3 + 1/4 + 1/5 + ... = ？？？（调和级数，几乎每个中学课本都说它发散到 +∞）

雅各布宣称：调和级数 = ∞。他的弟弟约翰却死活不同意。两人见面就吵，写信就吵，吵到不见面为止。

"哥哥的死证明他在所有事情上都是错的 — 但在数学上他错得最离谱。" —— 约翰·伯努利 1705 年（弟弟）

事实上：雅各布是对的。调和级数确实发散。但要严格证明，需要"夹逼"思想 —— 这要等 100 年才被欧拉和柯西完成。

📱今天有什么用？今天每个编译器里都有"无穷级数收敛判别"代码。你的电脑能算 π = 3.14159265358979...，就是用莱布尼茨级数 π/4 = 1 - 1/3 + 1/5 - 1/7 + 1/9 - ... —— 调和级数的近亲。

📖 等比级数
-300 欧几里得：「比 = 每个数都是前一个 r 倍」

🎯它是为了解决什么问题？

古希腊人发现：有一种求和特别简单 —— 每个数都是前一个数 r 倍的级数。例如 1 + 1/2 + 1/4 + 1/8 + ... = 2。

欧几里得在《几何原本》给出这个结果：只要 |r| < 1，等比级数收敛，且和 = a / (1 − r)。

"1 + r + r² + r³ + ... = 1 / (1 − r)，只要 r 小于 1。" —— 欧几里得《几何原本》

📱今天有什么用？这个公式每天都在你身边：

① 银行存款：每年利率 5%，无穷年后你的本息和 → 本金 / (1-0.05) ≈ 20 倍本金

② 音乐流媒体：声波是 1 + 0.5 + 0.25 + ... 这种高频振动

③ 药物残留：每天服一片药，每片残留 80%，无穷天后体内总量 = 5 片

📖 泰勒级数（进阶）
1748 欧拉：「e^x 就是个加法题」

🎯它是为了解决什么问题？

上一章 ch02 我们学过泰勒公式 —— 在 x=0 附近把 f(x) 展开成 x 的多项式。欧拉发现一个惊天事实：

有些函数 = 自己的无穷级数。

e^x = 1 + x + x²/2! + x³/3! + x⁴/4! + ...
sin x = x − x³/3! + x⁵/5! − x⁷/7! + ...
ln(1+x) = x − x²/2 + x³/3 − x⁴/4 + ...
1/(1−x) = 1 + x + x² + x³ + ...

欧拉写的《无穷分析引论》(Introductio in Analysin Infinitorum, 1748) 第一次系统给出这些 —— 他还第一次严格证明了它们为什么收敛。

"e^x 是一个无穷多项的加法 — 这就是指数增长的真正面貌。" —— 欧拉

📱今天有什么用？没有泰勒级数，就没有现代工程：

① GPS：4 颗卫星定你位置，要解 4 元方程组，每一步都在用泰勒级数

② 手机屏幕：HDR 渲染、"图像降噪"算法都是泰勒展开

③ AI 反向传播：梯度 = 损失函数的泰勒展开一阶系数

📖 傅里叶级数（应用级）
1807 傅里叶：「我能用 sin/cos 拼出任何函数」

🎯它是为了解决什么问题？

1804 年，拿破仑悬赏："热在固体里怎么传？"。一个数学老师 傅里叶 (Joseph Fourier) 发现：

"任何'在区间内画得出的形状'，都可以拆成无数 sin 和 cos 函数相加。"

他把这种"加"叫傅里叶级数：

f(x) = a₀ + Σ[aₙ·cos(nx) + bₙ·sin(nx)]

1807 年他在巴黎科学院报告，所有人都觉得他疯了。拉格朗日当场拍桌子："这绝不可能 —— 怎么可能是有限个三角函数的和！"

后来他的论文被拒，发表后被人嘲笑为"连收敛性都没证明"。但 15 年后（1822）他的《热的解析理论》终于出版，工程师们用它计算了桥梁、热交换器、声波，从此改变了世界。

"我震惊了整个巴黎 — 但工程师们不在乎对错，他们在乎好不好用。" —— 傅里叶 1811

📱今天有什么用？傅里叶级数在 3 个地方统治世界：

① mp3 / 视频压缩：把声波 / 像素拆成 sin + cos，扔掉小系数，省 95% 体积

② 心脏起搏器：心电图分析本质就是傅里叶级数

③ 5G 信号：手机的 OFDM 调制 = 傅里叶级数的工程化身

📖 交错级数 / 莱布尼茨判别
1675 一个"看正负号一替一换"的判断法

🎯它是为了解决什么问题？

有些级数是"一正一负一正一负"的（比如 1 - 1/3 + 1/5 - 1/7 + ...），这种交错级数可能收敛到 π 之类很酷的东西。

莱布尼茨判别法的精髓 5 个字：单调递减到 0。只要"绝对值越来越小"，正负相间地加，总会停在一个数上。

∑(−1)ⁿ⁻¹ aₙ 收敛条件：aₙ 单调递减且 → 0

直观解释：如果每一项都在变小，正负相间的"拉扯"越来越小，最终会"靠岸"停在一个数。

"正负拉扯就像拔河 — 越拔越稳，最后停在中间。" —— 莱布尼茨

📱今天有什么用？电力工程里的"交流电波形"分析就是交错级数 —— 正半周和负半周正负交替，要算总能量时就是交错级数的应用。

本题满分12分） 设 \(u_{n}(x) = \mathrm{e}^{-nx} + \frac{x^{n + 1}}{n(n + 1)} (n = 1,2,\dots)\) ，求级数 \(\sum_{n = 1}^{\infty}u_n(x)\) 的收敛域及和函数. （19）（

🎯 出题人考察点（这是高频考点！）

幂级数收敛域、和函数

🧭 解题思路（小白逐步版）

步骤 1 · 先判断逐项收敛

\(u_n(x)=e^{-nx}+\frac{x^{n+1}}{n(n+1)}\)。第一部分是等比级数 \(\sum e^{-nx}\)，收敛当且仅当 \(e^{-x}<1\) 即 \(x>0\)；第二部分是幂级数 \(\sum \frac{x^{n+1}}{n(n+1)}\)，收敛半径 \(R=\lim \frac{n(n+1)}{(n+1)(n+2)}=1\)，端点 \(x=\pm1\) 分别讨论。

步骤 2 · 并集求收敛域

两部分收敛域取交集：\(x>0\) 且 \(|x|\le1\)，端点 \(x=1\) 处两部分都收敛，故收敛域 \((0,1]\)。

步骤 3 · 分别求和函数

\(\sum_{n=1}^\infty e^{-nx}=\frac{e^{-x}}{1-e^{-x}}=\frac{1}{e^x-1}\)；\(\sum_{n=1}^\infty \frac{x^{n+1}}{n(n+1)}=(1-x)\ln(1-x)+x\)（利用 \(\frac{1}{n(n+1)}=\frac{1}{n}-\frac{1}{n+1}\) 裂项）。

① 写对方法 (4分)；② 计算过程 (5分)；③ 最终答案 (4分)

⚠️ 小白踩坑预警（错一个扣 2~4 分）

⚠️ 求收敛域忘记端点 \(x=1\) 的单独讨论；⚠️ 裂项求和 \(\sum\frac{x^{n+1}}{n(n+1)}\) 时忘记平移下标

📝 近五年真题 2 | 2022 数一 | 填空题 · 5分
已知 \(a_n = \int_0^1 x^n \sqrt{1 - x^2}, dx\)，求 \(\displaystyle \sum_{n=0}^{\infty} a_n x^n\) 的收敛域及和函数。

🎯 出题人考察点（这是高频考点！）

幂级数的收敛域；逐项积分；函数项级数求和

🧭 解题思路（小白逐步版）

步骤 1 · 求收敛域

\(a_n\) 是 \(\int_0^1 x^n \sqrt{1 - x^2}, dx\) 形式，当 \(|x| < 1\) 时 \(\int_0^1 x^n \sqrt{1 - x^2}, dx < \int_0^1 x^n, dx = \dfrac{1}{n+1}\)。
更精细地，用比值审敛法：
\(\lim_{n \to \infty} \left|\dfrac{a_{n+1} x^{n+1}}{a_n x^n}\right| = |x|\)
当 \(|x| < 1\) 时收敛。检查端点 \(x = \pm 1\)：
\(x = 1\)：\(\sum a_n\) 中 \(a_n \to 0\) 但 \(\sum\) 收敛性需进一步验证，由积分放缩可知 \(a_n \leq \dfrac{1}{n+1}\)，且 \(\sum \dfrac{1}{n+1}\) 发散（不能直接说发散），但 \(a_n = O\left(\dfrac{1}{n}\right)\) 时 \(\sum\) 发散。综合验证：\(|x| \leq 1\) 收敛，\(|x| > 1\) 发散。
收敛域 \([ -1, 1 ]\)。

步骤 2 · 求和函数

\(S(x) = \sum_{n=0}^{\infty} a_n x^n = \sum_{n=0}^{\infty} \left(\int_0^1 x^n \sqrt{1-t^2}, dt\right) x^n\)
注意：上面 \(x\) 是积分变量，下面 \(x\) 是幂级数变量——区分一下，设积分变量为 \(t\)：
\(a_n = \int_0^1 t^n \sqrt{1-t^2}, dt\)，则 \(S(x) = \int_0^1 \sqrt{1-t^2} \sum_{n=0}^{\infty} (xt)^n, dt = \int_0^1 \dfrac{\sqrt{1-t^2}}{1 - xt}, dt\)（当 \(|xt| < 1\)）。

步骤 3 · 化简

在 \([-1, 1]\) 上，\(|xt| \leq |x| \leq 1\)，且 \(t < 1\) 时 \(|xt| < 1\)。
\(S(x) = \int_0^1 \dfrac{\sqrt{1-t^2}}{1-xt}, dt\)。

💯 得分点（阅卷老师按点给分）

① 写出关键思路 (3分)；② 计算正确 (2分)

⚠️ 小白踩坑预警（错一个扣 2~4 分）

积分变量与幂级数变量混淆；逐项积分前提条件不满足（一致收敛未验证）；漏掉 \(x = \pm 1\) 端点检查

📝 近五年真题 4 | 2023 数一 | 填空题 · 5分
设 \(f(x)\) 为周期为 2 的周期函数，且 \(f(x) = 1 - x, x \in [0, 1]\)。若 \(f(x) = \dfrac{a_0}{2} + \displaystyle\sum_{n=1}^\infty a_n \cos n\pi x\)，则 \(\displaystyle\sum_{n=1}^\infty a_{2n} =\) ______。

🎯 出题人考察点（这是高频考点！）

傅里叶级数；余弦级数

🧭 解题思路（小白逐步版）

步骤 1 · 思维导图：傅里叶级数的两种解法

【题目特征】已知局部表达式，求傅里叶级数特定项的无穷和
【解法一：暴力积分（常规法）】
└─ ① 判断奇偶性：只有余弦项说明是偶函数，周期为2（半周期 \\(l=1\\)）
└─ ② 套用系数公式：\\(a_n = \dfrac{2}{l}\int_0^l f(x)\cos\dfrac{n\pi x}{l}dx\\)
└─ ③ 分部积分求出 \\(a_n\\) 的表达式，直接看 \\(a_{2n}\\) 的值

【解法二：赋特殊值法（邪修秒杀法）】
└─ ① 利用级数收敛定理（狄利克雷定理），代入特殊的 \\(x\\) 凑出要求的求和形式
└─ ② 找 \\(a_{2n}\\)：利用 \\(1+(-1)^n\\) 可以把奇数项消掉的特性
└─ ③ 分别代入 \\(x=0\\) 和 \\(x=1\\)，两式相加即可解出

【口诀】余弦级数偶函数，求和代点最快速；奇偶分离用加减，算错积分最痛苦。

步骤 2 · 邪修秒杀法（推荐）

原级数为 \\(f(x) = \dfrac{a_0}{2} + \sum_{n=1}^\infty a_n \cos n\pi x\\)。
令 \\(x=0\\)：\\(f(0) = \dfrac{a_0}{2} + \sum_{n=1}^\infty a_n = 1\\)（因为 \\(f(0)=1-0=1\\)）。
令 \\(x=1\\)：\\(f(1) = \dfrac{a_0}{2} + \sum_{n=1}^\infty a_n \cos n\pi = \dfrac{a_0}{2} + \sum_{n=1}^\infty a_n (-1)^n = 0\\)（因为 \\(f(1)=1-1=0\\)）。
将两式相加：\\(f(0) + f(1) = a_0 + \sum_{n=1}^\infty a_n[1 + (-1)^n]\\)。
注意 \\(1+(-1)^n\\) 的神奇性质：当 \\(n\\) 为奇数时为0，当 \\(n\\) 为偶数（\\(n=2k\\)）时为2。
所以式子变成：\\(1 + 0 = a_0 + 2\sum_{k=1}^\infty a_{2k}\\)。

步骤 3 · 计算 a_0

\\(a_0 = \dfrac{2}{1} \int_0^1 f(x) dx = 2 \int_0^1 (1-x) dx = 2 \left[x - \dfrac{1}{2}x^2\right]_0^1 = 2 \times \dfrac{1}{2} = 1\\)。
代入上式：\\(1 = 1 + 2\sum a_{2n}\\)，得出 \\(\sum a_{2n} = 0\\)。

步骤 4 · 常规法（备用）

套用公式 \\(a_n = 2\int_0^1 (1 - x) \cos n\pi x dx\\)。
使用分部积分法：
\\(= \dfrac{2}{n\pi}\int_0^1 (1-x)d(\sin n\pi x)\\)
\\(= \dfrac{2}{n\pi} \left[ (1-x)\sin n\pi x \Big|_0^1 - \int_0^1 \sin n\pi x d(1-x) \right]\\)
\\(= \dfrac{2}{n\pi} \left[ 0 + \int_0^1 \sin n\pi x dx \right] = -\dfrac{2}{n^2\pi^2} \cos n\pi x \Big|_0^1 = \dfrac{2}{n^2\pi^2}[1 - (-1)^n]\\)。
当 \\(n\\) 为偶数时，\\((-1)^n = 1\\)，所以 \\(a_{2n} = 0\\)。
既然每一项 \\(a_{2n}\\) 都是0，它们的和必然是 \\(0\\)。

步骤 5 · 易错点提示

【易错点】用常规法时分部积分符号搞错；忘记 \\(a_0\\) 的公式前面还有个 \\(\dfrac{2}{l}\\)；不明白 \\(1+(-1)^n\\) 可以用来提取偶数项。
